Prepare a separate layer for the import exercise. Enter K M L and K M Z import as the Layer Name, set Order to twenty, choose Data Layer, and select Add Layer. The returned row shows the new layer with no image. This keeps the imported geometry separate from the existing ground-floor drawing and the earlier Geo J S O N example.

On Custom Maps, select Import for the Community coordination centre. In Import Geospatial Data, select the dedicated Target Layer. Choose the fictional assembly-area K M L file, review the target again and select Import. The file contains one named polygon. The source files for this exercise are retained with the Academy so the example can be reproduced.

Import History now shows import dot K M L, Type K M L, and Complete. The returned form has reset its target selection, so choose the dedicated layer again before the next upload. Choose the access-area K M Z archive and import it. History now contains separate Complete entries for K M L and K M Z. A completed import still needs a visual geometry review.

This additional test selects the same target and uploads a K M L file with no placemarks. Its returned history row says Failed. The Error column explains that no placemarks with a point, line or polygon were found. Check the specific result and error for the intended run. Do not treat returning to the form as proof that useful geometry was imported.

Open Region Editor for the dedicated layer. The two successful imports are visible as separate polygons and named entries. Select each polygon to review Region Properties. Both imported areas are Custom regions; Searchable in dispatch and Dispatchable are checked in this example. Review those defaults before operational use. The import status describes processing, while the map and properties show what was actually retained.

On New Call, open Indoor Location and search for training. Both imported areas now appear as selectable results. No call is dispatched in this exercise. This pattern can bring reviewed planning areas into a search-and-rescue, security, wildland, industrial or community response department, alongside fire and E M S. Verify coordinates, naming and operational permissions before relying on imported reference data.
