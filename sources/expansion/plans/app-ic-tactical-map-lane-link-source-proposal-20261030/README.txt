IC tactical map lesson source

This package retains eight personally reviewed actual screenshots and their DOM observations, the exact eight-paragraph narration, the source-only candidate lesson, a sentence map and the original frozen inputs. The additional source-runtime-provenance.json separately binds the unchanged IC source snapshots without rewriting the original freeze.

Reproduce in a fictional training department through normal IC UI:
1. Open the existing training incident command board and select Tactical Maps.
2. Use the Add control in that section. Enter a specific Name and Description, choose an expiry and check its displayed value.
3. Save and read the returned named map card, count and expiry. The recorded prepared/saved clock times differ; verify the intended expiry before relying on it.
4. Use the intended lane pencil control, scroll to Attached Map, select the named map and Save.
5. Reload normally, reopen the same lane and check the persisted selection.
6. Return to Tactical Maps, read the saved card and open it. Confirm its matching header and actual resource context.
