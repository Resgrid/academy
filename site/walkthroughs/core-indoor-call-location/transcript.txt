Make indoor rooms searchable and retain a call reference
Audience: Department administrators, Dispatch coordinators, Facility and operations supervisors

Review the room and its search controls
In the ground-floor Region Editor, select the Briefing room polygon to open Region Properties. Review its Name, Room Type, Color and Description. Searchable in dispatch is checked, while Dispatchable is clear in this example. These are separate options. We will verify the search setting through New Call, rather than assuming both checkboxes mean the same thing.
Practice: Review the room and its search controls

Hide the room from new searches
Clear Searchable in dispatch and select Save Region. On New Call, open Indoor Location and search for Briefing. The returned search now says No results found. This removes the room from that new selection search. It has not deleted the underlying floor plan or the room polygon.
Practice: Hide the room from new searches

Restore the search option and verify it
Return to the same room’s properties, check Searchable in dispatch and save again. Repeat the Indoor Location search on New Call. Briefing room now returns as a selectable result. Dispatchable remains clear during this test. The actual returned option verifies which setting controls this search in the recorded system.
Practice: Restore the search option and verify it

Select the indoor reference and keep the outdoor position accurate
Select Briefing room from Indoor Location. Review the selected room name before saving the call. The outdoor location is separate. This fictional exercise also enters a latitude and longitude and uses Set Pin on Map to place the outdoor marker. Selecting an indoor room has not automatically supplied those outdoor coordinates. Review the outdoor map and the indoor reference together so responders have the intended context.
Practice: Select the indoor reference and keep the outdoor position accurate

Save pending and reopen the retained reference
After preparing the call information, select Save as pending, do not dispatch yet. The submit button still reads Create and Dispatch Call, so verify that the pending checkbox is selected before submitting this exercise. The returned Pending Calls list contains the saved call. Open View and confirm the Pending banner. Then use Update Call and scroll back to Indoor Location. Briefing room is still selected. This checks the persisted reference independently of the original form.
Practice: Save pending and reopen the retained reference

Distinguish a saved room from a live location
The floor plan and selected room are stored references. They do not establish who is currently inside the room, track movement or confirm physical arrival. Keep that distinction clear when briefing a crew. A community paramedicine or mental health team can use a reviewed coordination-room reference; search-and-rescue, security, wildland support and industrial teams can use equivalent named areas. Use verified local map information and the appropriate live-location tools separately. This exercise demonstrates room search and a saved pending-call reference.
Practice: Distinguish a saved room from a live location
