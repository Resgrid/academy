Open Archived Calls from the Omni Dispatch menu to review calls that have already closed. This is useful when a caller asks about earlier activity or a team needs context for a follow-up.

Choose Filters to see the available choices, including Closed As. Use the status filter to focus on the type of closeout you need to review.

Use the search box to find the archived call by name. Here we find the fictional community standby. Check the call number and closed status before opening it.

Call Details keeps the original description with its call number. A security dispatcher could use it to identify an earlier site incident. A wildland contractor could use it to confirm which exercise was closed.

Open History to review previous calls at this location when they are available. Check the exact call number and the details before using an earlier call as context.
