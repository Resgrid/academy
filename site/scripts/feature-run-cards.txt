Run cards and recommendations

Recommended resources for each call type or area.

Why it helps
Review candidate coverage before enabling operational use.

How to configure it
Build run cards for your most common calls, then turn on recommendations.

Before you begin
Feature access enabled by your system operator

Examples for your department
Community paramedicine and mental health response: Run cards and recommendations: Use an approved operational request type for a visit or mobile response; keep clinical triage and sensitive detail under the service’s procedures.
Search and rescue: Run cards and recommendations: Use Rescue or a reviewed search type and clear staging information; select the appropriate team.
Security companies and departments: Run cards and recommendations: Use Investigation or a reviewed patrol incident type with the correct site and selected resources.
Wildland contractors: Run cards and recommendations: Use a reviewed assignment or incident type and staging details; select crew and support resources.
Industrial emergency response teams: Run cards and recommendations: Use a reviewed facility incident type and access location; select the facility team and specialist equipment.
