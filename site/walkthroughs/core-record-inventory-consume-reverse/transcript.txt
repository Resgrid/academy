Record inventory use and reverse an incorrect entry
Audience: Department administrators, Inventory managers, Records officers

Start with the intended saved record
Begin on the saved fictional Work draft. Check its External I D, training inventory reference, location and narrative so this stock movement belongs to the intended exercise. This record remains Draft throughout the lesson. Select Inventory usage on the record’s top action bar. Connecting usage to a record keeps the supplies used for an assignment alongside the record that explains the work.
Practice: Start with the intended saved record

Verify the source stock before using it
Check the current baseline in Inventory, under On hand. Choose Academy training batteries in Items and select Filter. The Station row has fourteen packs, while Unit has five and Personnel has zero. These are separate locations. This exercise will consume from Station explicitly, so compare against that row. Recording the starting quantity gives you a concrete balance to verify after saving and after correcting the entry.
Practice: Verify the source stock before using it

Read the immediate stock-impact controls
Back in Inventory usage, read the notice above Recorded usage. Saving changes stock immediately, and those changes remain if a draft or amendment is abandoned. A correction requires an explicit reversal. Keep Usage type set to Used for these training batteries. Leave Existing consumption transaction I D blank because we are creating a new consumption. That optional field instead attaches a completed transaction without consuming the same stock again. The controlled-item notice describes a separate independent witness process.
Practice: Read the immediate stock-impact controls

Choose the item, location, lot and quantity
Under New consumption, select Academy training batteries, with packs as the unit of measure. Choose Station as Source location and Academy Lot A under Lots. Assets stays blank for this ordinary stock item. Enter two as Amount and add a clear training-only Note about the fictional radio exercise. The source help explains the responding-unit and station fallback; choosing Station explicitly makes our intended source unambiguous. Review those fields, then select Save usage once.
Practice: Choose the item, location, lot and quantity

Verify both the usage record and reduced stock
The page returns Usage saved and supporting evidence captured. Recorded usage now contains the batteries, Used, plus two packs, the note and a Ledger entry link. The positive number here describes the amount used. Check On hand again: Station has fallen from fourteen to twelve packs. The Unit row still has five. Compare the saved usage row with the physical stock balance so you can see that this is consumption, rather than a stock increase.
Practice: Verify both the usage record and reduced stock

Prepare an explicit full reversal
To correct this exercise, expand Reverse usage on the recorded row. The help says this is a full reversal that keeps the original usage in history. Enter a Reason for correction explaining that the two-pack exercise quantity was entered in error and should be restored. Leave the optional witnessed reversal transaction I D blank for this ordinary training item. Select Reverse usage. Correcting an amount or item would require reversing the old usage and then recording its replacement; this lesson demonstrates the reversal.
Practice: Prepare an explicit full reversal

Read the correction history and restored balance
The saved history retains the original plus-two-pack row and marks it Reversed. A second row shows minus two packs, the correction reason and a reference to the original usage. The original entry was not silently overwritten. Return to On hand and verify that Station is back to fourteen packs. Unit still has five and Personnel still has zero. This readback establishes the result of the full reversal in this fictional exercise.
Practice: Read the correction history and restored balance

Trace the reversal into the ledger
Open the reversal’s Ledger entry link. The movement detail shows Adjust for the training batteries at Station, with a positive quantity of two, the correction reason and a reference to this record. The record’s negative usage correction and the ledger’s stock-restoring quantity describe different sides of the same action. Use the linked ledger detail when reconciling why a balance changed, rather than relying only on a current quantity.
Practice: Trace the reversal into the ledger

Inspect the current and superseded evidence
Return to the record and open Supporting evidence. The current Draft capture now contains two inventory usage entries. The earlier one-entry Draft capture remains beside it as Superseded. Each has its own captured time, source version and Checksum. The page explains that a correction creates a new capture and keeps the earlier evidence in history. The record is still a draft; no finalization or signature was performed in this example.
Practice: Inspect the current and superseded evidence

Use a traceable supply workflow in your department
Use this same record, verify and correct process for the supplies your department manages. Search-and-rescue teams and security departments can track battery use; wildland contractors and industrial emergency teams can connect their consumables to operational records. Community paramedicine and mental health response teams, fire departments and E M S organizations can use the same permitted inventory controls. For controlled items, follow the independent witness notice shown in the form. Keep the assignment record, stock balance and retained correction history consistent.
