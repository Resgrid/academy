In Core Inventory, this recorded exercise returns the remaining issued stock and checks where the balance went. Open On hand to review the current item and location. Use Items to select Academy training batteries and choose Filter. The starting snapshot shows thirteen at Station, five at Unit and one at Personnel: nineteen altogether. These figures follow earlier usage, so they are later than the separate twenty-pack receipt example.

Choose Issuances. Find the training batteries row and compare Location, Outstanding and Status. This row says Personnel, one outstanding, and Partially returned. Personnel identifies the holder category here; it does not print a person’s name. Choose the row’s Return action. The Return window names the batteries and asks for Amount, Destination location, Status and Note. Opening this form has not recorded a return.

For this example, Amount is one and Destination location is Station. Read both before continuing: the quantity is coming back from the issuance holder to that destination. Add a useful Note explaining the return. Ours clearly marks a fictional software exercise with no physical movement. Check the complete note rather than relying on a shortened description elsewhere.

Status describes the condition the equipment came back in. Out for repair is one available choice, shown here without submitting it. Damaged is another choice, also left unsaved in this exercise. We restore In service for the final training return. Select the condition that matches your authorized record; choosing a software label does not establish a physical inspection or repair.

Review Amount, Station, In service and the full Note together. When the intended return is correct, select the Return button at the bottom once. Read the resulting Issuances row. It now says Returned with zero outstanding, and its Return action is gone. That readback establishes the stored result; the prepared form alone did not. Avoid submitting again while waiting for a result.

Choose History to check the recorded movement. Filter Items to the same training batteries. The new top Return row shows one moving from Personnel to Station, with our complete training note. Earlier rows remain separate: Consume records one used pack, and the older Issue row records two, with Matthew Casey named in its note. Read the movement, quantity, direction and note together so an older return is not mistaken for the new one.

Return to On hand for the balance check. The fresh filtered table now shows fourteen at Station, five at Unit and zero at Personnel. The total is still nineteen. Returning the issued pack moves its recorded holding; it does not restore the pack consumed earlier or create an extra receipt. Compare this result with the starting balances and the new ledger entry.

The example issuance is now Returned with zero outstanding. Do not submit another return against it. For practice, use a different approved issuance that still has stock outstanding and read its current balances. The same return and reconciliation pattern serves fire and EMS, community paramedicine and mental health teams, search and rescue, security departments and companies, wildland contractors, and industrial emergency response teams.
