Open Checklists with Engine 51 selected. The left panel shows one of one roles, Released and No Active Call. Under Start checklist, find Engine 51 daily readiness, then choose the Engine 51 target directly beneath it. The Ambulance 61 template also offers an Engine 51 button, so check the form name before starting. This published training form is already available.

The form identifies Engine 51 and Version 1. The first of three items is Equipment ready for the exercise, marked Required and Critical. For this software exercise, select Pass. Add a Note stating that this is a software walkthrough answer and no physical equipment inspection was performed. Read the answer and note together, then choose Next. The recorded Pass is a simulated exercise answer.

Next opens Stock and supplies recorded, item two of three. Select Pass for the simulation and add a note that no actual stock audit was performed. The item note explains the meaning of this answer to a later reader. Review the item name, selected answer and note before choosing Next. Use the same review habit for a SAR cache or security patrol kit.

Item three is Handover notes reviewed. Select Pass and add the fictional handover note. Below the item controls, the general note states that these simulated answers do not certify operational readiness or an actual equipment inspection. In this example, location stays blank. Choose Save progress to retain the work before submission. For practice, keep the item note separate from the whole-run note.

Back on Checklists, Local drafts shows Draft 1. History also contains a timestamped Engine 51 run. Choose History and inspect that saved entry. The target name and time help distinguish it from another exercise. A history entry alone does not establish submission. For a community care vehicle, check the correct target just as carefully before reopening saved work.

Reopened in the same tab, the first item still shows Pass, its equipment note and the general software-only note. Review those values before continuing. We are looking at the first answer; the other items are not expanded together here. Save progress and Submit checklist are still available. For practice, reopen a saved exercise and compare its first answer and run note with what you saved.

When review is complete, choose Submit checklist. The returned sheet shows Submitted, Score 100, and Close. Save progress and Submit checklist are no longer available. Here, one hundred is the result of the entered exercise answers. It does not establish physical equipment condition. For practice, identify the returned submitted state before treating the software run as finalized.

This final sheet was reopened from refreshed History in the same tab. Submitted and Score 100 remain visible, along with the retained training notes. Use the same target, answer, note and saved-review habit for a wildland vehicle or industrial support equipment, with your team's appropriate form. This browser exercise does not establish offline, browser-restart or device-location behavior. For practice, explain the saved software result and the physical checks that your team still needs to perform.
