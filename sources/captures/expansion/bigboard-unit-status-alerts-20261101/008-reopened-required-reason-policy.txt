Personnel Mapping Settings
Allow Status with No Location Data to hide previous location
Allow a personnel status without a location to replace the previous location-bearing state. This can remove a marker.
If enabled and a status comes in for that user (i.e. Standing By) without a geolocation it'll hide the users location on the map. Otherwise the last location of the user will be shown even if it's older.
TTL In Minutes for Personnel Locations
Maximum personnel location age in minutes. Zero keeps stale positions visible without an age limit; assess actual ping ages.
In Minutes, how long locations are valid for to be shown in the map. I.e. a value of 60 would mean a marker for a person would show on the maps for up to 60 minutes, afterwards would not be shown. Setting 0 disables TTL and a location, no matter how old, will be shown on the map.
Units Mapping Settings
Allow Unit Status with No Location Data to hide previous location
Allow a unit status without a location to overwrite earlier location data. Check hardware and app updates together.
If enabled and a status comes in for that unit (i.e. In Quarters) without a geolocation it'll hide the units location on the map. Otherwise the last location of the user will be shown even if it's older.
TTL In Minutes for Unit Locations
Maximum unit location age in minutes. Zero retains stale unit locations indefinitely in supported map consumers.
In Minutes, how long locations are valid for to be shown in the map. I.e. a value of 60 would mean a marker for a unit would show on the maps for up to 60 minutes, afterwards would not be shown. Setting 0 disables TTL and a location, no matter how old, will be shown on the map.

Department Mapbox Override
Use Department Mapbox Map
Use the department map provider override. Turning it off on the owning screen removes the stored style and token.
When enabled, this department's own Mapbox style and public token replace the Map Style above everywhere: the department website views (even when the system stays on Leaflet) and the Dispatch, Responder, Unit, IC and BigBoard apps, which load the token and style the next time they fetch their configuration. The custom style is used in both light and dark mode.
Mapbox Style Url
Custom map style reference. Verify the provider style and credential together; disabling the override deletes this value.
Supported values are `mapbox://styles/...` or `https://api.mapbox.com/styles/v1/...`.
Mapbox Public Access Token
Map-provider access token. Only presence is reported. Disabling the override deletes it and requires re-entry to restore.
Use a public (pk.) Mapbox token intended for website and mobile client-side map rendering for this department. It is sent to every member's browser and app; never use a secret (sk.) token.
