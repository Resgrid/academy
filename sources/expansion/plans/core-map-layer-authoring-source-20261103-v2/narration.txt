On New Layer, enter a recognizable Name. This example uses Outreach staging example. Is Visible By Default starts checked. Leave Is Destination clear for this drawing-only reference. That option controls whether layer coordinates participate in address searching; it is not the same as displaying a layer. Color is blue here. Use a name and color your department can distinguish from operational calls and resources.

In Layer Elements, pan and zoom to the intended practice area. Select the rectangle-shaped drawing tool on the left. Cancel is available while drawing. Click the first corner, then the opposite corner to finish the rectangle. The outlined, shaded area is the saved shape you are preparing. It is a fictional planning reference, not an official hazard boundary or a live tracking area.

Select the marker-shaped tool and click the intended point once. Inspect the marker and rectangle together before saving. Scroll below the map and select Add Layer. The returned Layers list shows Outreach staging example with an Item Count of two. Those two stored items are the rectangle and marker. Check the count to catch accidental duplicate points.

Select Edit on the Outreach staging example row. The stored name, blue Color and checked default-visibility option return. Scroll down to inspect the retained rectangle and marker. Reopening the layer verifies that its geometry survived the save; a successful return to the list alone would not establish that the intended shape was retained.

Clear Is Visible By Default. Scroll down and select Edit Layer to save the change. From the returned list, reopen the same layer. Its default-visibility checkbox is now clear, while the name, color and drawing remain stored. This changes the department default. It does not delete the layer or force every existing browser to discard its own map visibility selection.

On Mapping, inspect the Map layers section. This browser already has a saved display choice for Outreach staging example, so compare that checkbox with the department setting you just reopened. Select or clear the named layer to control this map display. After clearing it and reloading, its checkbox remains clear. This is a display choice, separate from deleting the underlying drawing. Departments can use reviewed layers for search-and-rescue planning, security patrol areas, wildland logistics, industrial response or community paramedicine and mental health support, as well as fire and E M S. Keep the drawing purpose clear and confirm the intended map extent.
