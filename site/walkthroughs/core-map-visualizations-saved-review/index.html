Filter, save and reopen a map visualization

Choose a call-demand template, review its date and display settings, filter Investigation calls, save a private view, and verify its retained settings and location completeness.

Audience: Department administrators, Operations and planning supervisors, Department analysts

Before you begin

  • Authorized access to Map Visualizations and a separate fictional training department.
  • Permitted calls with appropriate types, dates and location data for the question you want to review.

Chapters

  3. Choose the call type and observe the changed result

Download video · Download captions

Step 1

Choose a library starting point

In Map Visualizations, start on Library and search for Calls by type. Read the matching template description: it shows recent calls as dots coloured by call type. Select that result, then open Customize. The heading changes from the earlier Call hot zones view to Calls by type. Choosing a template gives you a starting configuration that you can inspect before saving your own view.

Practice

Choose a library starting point

Step 2

Review the date and time scope

Under When, this template has Date range set to Last ninety days. Days of the week and Hours of the day are shown below it. The page explains that leaving those buttons unselected includes every day and hour, using the department time zone. Keep this time scope for the exercise. Check these controls whenever you compare demand, because a different time window answers a different question.

Practice

Review the date and time scope

Step 3

Choose the call type and observe the changed result

Scroll within Customize to Which calls and open Call types. The unfiltered view shows seventeen calls and eighty-two percent with a location. Check Investigation, then close the selector. Its button now reads Investigation, and the result changes to eight calls with sixty-three percent having a location. This shows the effect of the selected filter on the same time window. The other visible selectors remain All in this exercise.

Practice

Choose the call type and observe the changed result

Step 4

Distinguish matching activity from mapped activity

Compare the filtered summary with the map legend. Eight calls match the filter, while the Investigation legend contains five located entries. The summary rounds that location completeness to sixty-three percent. A map shows where located activity appears; its dots do not account for calls that lack a usable location. Check this measure before treating a sparse map as evidence that little work occurred. These numbers describe the fictional recorded dataset.

Practice

Distinguish matching activity from mapped activity

Step 5

Inspect the actual layer display choices

In Layers, review the enabled Calls layer. Data is Calls, described as one point per call at the call location. Show as is Dots, Color by is Call type, and Value is Count. Opacity and Dot size are separate display controls below these choices. Keep the shown configuration here. Reading the data source and display choices together helps you explain what the symbols represent, rather than judging only their appearance.

Practice

Inspect the actual layer display choices

Step 6

Name the private view and save it

Select Save as new. In Save as a new visualization, enter the fictional name shown here and a Description that records the purpose, date scope and filter. Leave Share with the whole department unchecked for this private exercise. The choice is visible beside the form, so check it deliberately before saving. This walkthrough saves a view for the current user. Select Save.

Practice

Name the private view and save it

Step 7

Verify the saved library entry

Open Library and check Saved visualizations. Under My visualizations, the named Investigation demand review appears with its description and Only visible to you label. The same saved name is now the page heading. These are returned application results after the save, rather than the unsaved form. Confirm the intended entry and visibility label before using the view again.

Practice

Verify the saved library entry

Step 8

Reopen and verify the retained settings

Open the saved visualization in a fresh page and return to Customize. Date range still reads Last ninety days. Scroll to Call types and check that Investigation is retained. Then inspect the layer again: Calls, Dots, Call type and Count remain selected. This reopening check verifies the stored configuration beyond the form where it was prepared. It does not depend on remembering the settings from the earlier screen.

Practice

Reopen and verify the retained settings

Step 9

Read the saved map and its supporting summary

With the side panel closed, read the saved map and Investigation legend together. Scroll below it to see the eight-call total, location percentage, When calls come in grid, and Most common call types summary. The latter still shows Investigation and eight. Response-time cards contain dashes in this view, and the page explains their data and layer requirements. A dash is not a measured zero-minute response. Use the displayed results for the question this view actually answers.

Practice

Read the saved map and its supporting summary

Step 10

Use repeatable views across department types

The same process can support community paramedicine and mental health response planning, search-and-rescue activity reviews, security service demand, wildland contractor workload, industrial emergency response, and fire and E M S departments. Choose the permitted call types and time scope relevant to your team. Inspect the display settings, check location completeness, save the intended visibility, and reopen the result. A useful planning view is one whose filters and data limitations you can explain.
