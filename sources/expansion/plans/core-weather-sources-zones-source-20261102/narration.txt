Open Weather Alerts settings with department administration access. Source configuration, monitoring-zone configuration and notification policy are separate parts of this page. In this fictional department, Enable Weather Alerts is unchecked and the display threshold is Moderate. We will retain that training policy while configuring and checking a source and a named monitoring zone. No member notification is demonstrated in this exercise.

In Add or Edit Source, enter a recognizable Source Name. Choose National Weather Service as Source Type. This example enters I L in Area Filter for Illinois. The field accepts a comma-separated list and stores the normalized filter. The API Key field is blank here. Poll Interval is fifteen minutes. Clear Active while preparing this training source, then select Save.

The returned Alert Sources row shows the saved name, National Weather Service, the stored I L filter and fifteen-minute interval. Its status is Inactive and Last Poll says Never Polled. The O K badge is not proof that this source has contacted its provider: there is no completed poll in this example. Review the saved status and last-poll evidence before deciding a feed is operational.

Select Edit on the source row. Change Poll Interval to thirty minutes and leave Active clear. Select Save. The fresh source row now shows thirty minutes, Inactive and Never Polled. Reopen Edit to verify the thirty-minute value in the form as well. Choose a polling interval deliberately for your provider and department; a saved interval by itself does not demonstrate a successful provider request.

Use Manage Zones to open Monitoring Zones. Enter a clear Zone Name, then the latitude and longitude in Center Location. This fictional downtown reference uses a five-mile Radius. Zone Code is optional and is blank in this example; do not invent a provider’s zone code. Mark Primary Zone and leave the zone Active. Select Save Zone. The returned row retains its center, five-mile radius, Primary badge and Active state.

Select Edit on the saved zone row. The form reopens with the stored name, center, five-mile radius and checked options. Change Radius to eight miles. Select Save Zone again. The returned row shows eight while retaining Primary and Active. This round trip verifies the stored configuration. Confirm actual alert coverage separately; this recording does not demonstrate a live alert intersecting the zone.

Select Disable on the monitoring-zone row. Its badge changes to Inactive and the action changes to Enable. The name, center and radius remain saved. Select Enable to restore the Active state. Use these status controls when reviewing which configured zones should be available, and verify the resulting badge after each change. This exercise retains the active eight-mile primary training zone.

Return to Weather Alerts and inspect Active Weather Alerts. This department has no active alerts, and the configured source remains inactive and never polled. The global training policy is still disabled. A security company, search-and-rescue team, wildland contractor, industrial response team or community paramedicine and mental health program can document the relevant operating areas, just as fire and E M S can. Before operational use, verify the intended source’s provider results, monitoring coverage and delivery policy with the responsible department administrator.
