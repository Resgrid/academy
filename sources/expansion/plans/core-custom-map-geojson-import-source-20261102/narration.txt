Start with the intended Custom Map and open Layers. For this exercise, prepare a separate layer named G I S import, set Order to ten, and choose Data Layer as its Type. Select the fictional floor-plan image under Layer Image so the imported shapes will have readable context. Select Add Layer and verify the saved DataLayer row. The earlier ground-floor layer remains listed separately.

Return to Custom Maps and choose Import for the intended map. Set Target Layer to the G I S import layer. The page lists GeoJSON, K M L and K M Z as supported formats; this walkthrough uses GeoJSON only. Use Choose File to select the supplied fictional export containing two named polygons. Check the target and selected file together, then select Import once.

Read Import History after the upload finishes. This recorded run has a GeoJSON row with Complete status, a date and a blank Error column. The history uses the generic name geojson-import dot json for this run. Completion confirms that processing finished; the next step is to inspect the actual regions. The form above the history is ready for another upload, so its current target selection is a separate form value.

Open Region Editor for the G I S import layer, and wait for the image and shapes to load. Both Training room, followed by import, and Equipment, followed by import, appear in Regions. Their blue polygons sit over the corresponding fictional spaces on the plan. Compare the names and boundaries with the source file and intended layer. This visual check establishes more than the Complete history entry alone.

Select the training-room boundary to open Region Properties. Its imported Name and Description are present. In this recorded example, the initial Type is Custom, the Color is blue, and both Searchable in dispatch and Dispatchable are checked. Review these application settings after an import rather than assuming every property in an outside file became the intended Resgrid setting. The form shows what this region actually contains.

Change Type to Room and choose the amber Color shown here. Clear Searchable in dispatch and Dispatchable for this local review exercise, then select Save Region. Reopen the boundary after reload. The shape is amber, the list says Room, and the form retains both unchecked options. The original name remains. This distinguishes the prepared changes from the saved region that the application now returns.

Repeat the review for Equipment. Set its Type to Room and clear both availability options, then select Save Region. Reload and select that boundary again. Its name, Room type, blue Color and unchecked options are retained. Both imported regions are still listed, and neither has a Dispatchable badge in this final view. Reviewing one imported shape does not replace checking the others.

Return to Import History. The original completed run remains available after the region edits. The new-upload form now shows the ground-floor layer, which is the first choice in its list. For a subsequent file, deliberately select the intended Target Layer again before importing. Use the history to review the completed run and the form to prepare the next operation; they show different parts of the workflow.

This process can help security companies, search-and-rescue teams, wildland contractors and industrial emergency teams bring permitted site areas into Resgrid. Community paramedicine, mental health response, fire and E M S departments can use the same checks for appropriate coordination locations. Choose the correct file and target layer, inspect the imported geometry, review each region’s application settings, save, and reopen the result before relying on it.
