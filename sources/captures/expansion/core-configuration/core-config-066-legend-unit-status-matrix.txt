- heading "How an icon is picked" [level=4]
- list:
  - listitem: An icon uploaded for the type or role for that exact priority or status.
  - listitem: Otherwise the type's or role's own uploaded icon, with a badge in the color of the priority or status.
  - listitem: Otherwise the built-in pin in the color of the priority or status.
- paragraph: A priority or status with no meaning set is colored by what its name suggests, such as Emergency or Out of Service; one whose name suggests nothing shows a gray pin, as does a unit or member that has set no status. Set meanings on the Custom Statuses and Call Priorities pages to be sure.
