On the Calls tab in Omni IC, choose New Call. This walkthrough uses a fictional coordination exercise. Create a call only when your department has authorized you to do so.

Enter a short name and use Nature to explain what the team needs to know. Select the priority and call type. Here we use Routine and Investigation so the exercise is easy to distinguish in the list.

In Call Location, enter the verified coordinates for the exercise. A clear location matters whether you are coordinating a search, an industrial drill, or a community standby.

Open Select Recipients and check the audience before creating the call. The only selected person here is the signed-in training user. The Done button shows one selection.

Back on the form, check Dispatch To again. Confirm the intended recipient before choosing Create. If the audience shown is wrong, change it before you submit.

Find the call in the list. Here the server returned a call number and the call is marked Assigned to me. A queued call has not been dispatched yet, so check for the server result before relying on it.

Open the saved call and check the name, number, and map. The detail page keeps that context with the call's notes, images, and files.

Open Call actions, then choose Edit Call. Change the existing call so the revised instruction stays with the same incident number.

In Nature, update the briefing instruction. The example tells the crew that the briefing moved to the marked staging point.

Scroll to the end of the form and choose Save. Keep the existing recipient scope unless the exercise calls for a change.

Reopen the same call and confirm the revised briefing appears. Then open Files to add a supporting document that belongs with this call.

Choose Add File and select the fictional briefing from the device's file picker. Use a file that your department permits you to attach to the incident.

Wait for the briefing file to appear in Call Files. Its visible name lets you confirm you selected the right document.

Close and reopen the Files panel. The briefing is still listed on the same call. This is useful during a handoff because the next operator can find the latest briefing alongside the incident details.
