Start on the Resgrid Dispatch sign-in screen. Before entering your credentials, check the server shown above Username. This exercise uses the Academy training department. Use the server your department provided when you sign in for a real shift.

If you need to change the connection, select Change Server URL. The Server URL field takes the address of the Resgrid API. The note below the field explains the format. Use Save to apply a change or Cancel to keep the current connection. On the sign-in screen, Sign in with SSO is available for departments that have set up single sign-on.

After you sign in, confirm that you are on the Dispatch Console. Active Calls, Pending Calls, and Scheduled Calls describe different stages of work. The resource lists show who and what is available. Use the menu to reach Settings, where you can confirm the signed-in account and find the workstation controls.

Under Account, open Shared device for a workstation that several people use. Turn on This is a shared device and enter a short label that makes the station easy to recognize. Here we use Academy Dispatch Desk. The form says the setting takes effect the next time someone signs in. Select Save to return to Settings.

Open Shared device again and confirm that the label and switch were saved. A recognizable label helps people distinguish this workstation from their own devices. Each person signs in for their shift and uses their own verification when the app asks. Cancel closes this readback without changing the saved setting.

Back in Account, open Sign-in and security. This screen shows whether an authenticator app is set up, which passkeys exist for this app, and recent verifications. Check those details before relying on a shared workstation for a handoff. If your department requires another verification method, follow its setup process before the next shift.
